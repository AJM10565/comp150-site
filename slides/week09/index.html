Hook: 16 possible answers

Two inputs, A and B, give 4 rows: 00, 01, 10, 11.

So the output column of any two-input truth table is a 4-bit number.

There are only 24 = 16 of them: 0000 through 1111.

Every logic operation we meet today is one of these 16.
Watch the map in the corner: each time we meet one, we circle it.
How many can we find, and can we build all of them?

Boolean Algebra, Truth Tables, and Digital Circuits

  • Recall boolean expressions in Python:
    • Logic operations AND, OR, and NOT.
  • Algebraic notation:
    • For truth tables, we use 1 and 0 for True and False.
    • A or B is written with a + sign: A + B
    • A and B is written like multiplication: AB
    • not A is written: A'
  • Because there are only a few possible input values, we can build a truth table to get the results of all possible combinations.

Circuits

  • Circuits are set up with a voltage source and opportunities for wires to be grounded.
  • The circuits are set up with electrical resistances, so if a wire is connected to ground, it is grounded, whether it is also connected to a voltage source or not.
  • V_in is always connected to a source that might have a voltage on it, be grounded, or be disconnected, while V_out may either be disconnected or grounded.

The odometer idea

  • A 4-bit register is like a car odometer with 4 digits: it can only show 16 values.
  • Count up from 1111 and it rolls over: 1111 + 1 = 1 0000, and the extra 1 falls off the end, leaving 0000.
  • So 1111 is the number that gives 0 when you add 1. That is exactly what −1 does!
  • Likewise 1110 + 2 rolls over to 0000, so 1110 acts like −2, and so on.

Reading a two's complement number

  • Give the leftmost bit a negative weight. For 4 bits the weights are −8, 4, 2, 1.
    • 1011 = −8 + 0 + 2 + 1 = −5
    • 0110 = 0 + 4 + 2 + 0 = +6
    • 1111 = −8 + 4 + 2 + 1 = −1
    • 1000 = −8 = −8 (the most negative 4-bit number)
  • For 8 bits the weights are −128, 64, 32, 16, 8, 4, 2, 1, so the range is −128 to +127.

Why "flip and add 1" works

  • Add any number to its flipped version: every column is 0 + 1 or 1 + 0, so you get all 1s.
    • 0101 + 1010 = 1111
  • And 1111 is −1 (the odometer). So: x + flip(x) = −1.
  • Rearrange: flip(x) = −1 − x, so flip(x) + 1 = −x.
  • That is the whole trick. It is called the two's complement of x.

The hardware: one circuit adds and subtracts

  • Put an XOR gate on each bit of B, with its other input a control wire called SUB.
    • SUB = 0: B XOR 0 = B, so B passes through unchanged → the circuit adds.
    • SUB = 1: B XOR 1 = NOT B, so every bit flips → that is the "flip" step.
  • Also feed SUB into the carry-in of the rightmost full adder. When SUB = 1 that adds the extra +1.
  • Flip + add 1 = −B, so the adder computes A + (−B) = A − B.
XOR (0110) used as a "controllable NOT". One chain of full adders + one XOR per bit = adder and subtractor.

Exercise 8 (A): what a full subtractor does

  • A full subtractor handles one column of a subtraction, like one column of long subtraction by hand.
  • Three inputs: the two bits A and B, and a borrow-in (did the column to the right borrow from us?).
  • Two outputs: the difference bit D, and a borrow-out (do we need to borrow from the column to our left?).
    • D = A ⊕ B ⊕ borrow-in (the same XORs as the full adder's sum)
    • borrow-out = 1 when A is too small: A'B, or A and B are equal and a borrow came in

Exercise 8 (A): what real computers do

  • A chain of full subtractors works, but it is a second circuit next to the adder.
  • In practice, CPUs use the trick from the two's complement slides: A − B = A + (−B).
  • The adder-subtractor (one XOR per bit + SUB into the carry-in) gives subtraction from the same adder chain.
  • Fewer circuits, less space on the chip, one design to get right.

Exercise 8 (B): the hardware

  • Step 1, partial products: AND every bit of A with every bit of B. For 4-bit numbers that is 4 × 4 = 16 AND gates, all working at once.
  • Step 2, add them up: rows of full adders sum the shifted partial products.
  • This layout is called an array multiplier: a grid of AND gates feeding a grid of adders.
  • So multiplication needs nothing new: just AND gates and the adders we already built.

Exercise 8 (B): shift-and-add in Python

def multiply(a, b):
    result = 0
    shift = 0
    while b > 0:
        if b & 1:                    # is the lowest bit of b a 1?
            result += a << shift     # add a copy of a, shifted left
        b >>= 1                      # move to the next bit of b
        shift += 1
    return result

print(f"{6:04b} x {5:04b} = {multiply(6, 5):08b} = {multiply(6, 5)}")
0110 x 0101 = 00011110 = 30
<< shifts bits left (×2 each place), >> shifts right, & is bitwise AND.
