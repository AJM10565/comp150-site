Strings

A character is a single symbol: 'A', 'g', '5', '%'.
A string is a group of characters. Quotes tell Python "this is text, not code":

name = "Ada"
greeting = f"Hello, {name}! You are {36} years old."
print(greeting)   # Hello, Ada! You are 36 years old.

The f-string: put an f before the quote, and anything in {braces} gets evaluated and embedded. You'll use this constantly.

Naming things: the rules

Hard rules (same for variables and functions — break these and Python errors):
1. Start with a letter or underscore — never a digit
2. Letters, numbers, underscores only — no spaces, no special characters
3. Not a reserved word (if, for, while, def, return…)
4. Case-sensitive: myVariable ≠ myvariable
Conventions (break these and future-you is sad):
snake_case for variables and functions · UPPERCASE for constants · descriptive names · leading underscore = "internal, hands off"

Truthiness

Non-boolean values also count as true or false in a condition. Falsy in Python:

None · False · zero (0, 0.0) · empty things: '', [], (), {} — everything else is truthy
if 'hello':   # truthy — non-empty string
    print('True')

if []:        # falsy — empty list
    print('True')
else:
    print('False')

Powerful for concise code — and a source of subtle bugs when you forget the rules.

Control flow: if / elif / else

def check_age(age):
    is_adult = age >= 18
    is_teenager = 13 <= age < 18
    print(f"Age provided: {age}")
    if is_adult:
        print("You are an adult.")
    elif is_teenager:
        print("You are a teenager.")
    else:
        print("You are a child.")

check_age(20)

Why three keywords?

if — "check this condition." The gate.

elif — "only if the ones above failed, check this instead." Chains checks so exactly one branch runs — no double-counting, no gaps.

else — "if everything above failed, do this." The catch-all: guarantees something happens.

Order matters: Python checks top-down and takes the first branch that's true. What happens to a 16-year-old if we put the is_teenager check first? …and why does it still work?

Lists

An ordered collection of items — the workhorse data structure. Items sit at numbered positions (indexes) starting at 0:

numbers = [10, 20, 30, 40, 50]
print(numbers[0])     # 10  — first item
print(numbers[4])     # 50  — last item
print(len(numbers))   # 5   — how many

numbers.append(60)    # lists are mutable: they can grow and change

Ordered · changeable · can hold anything (but usually one type). Loops and lists are best friends — next slide.

for loops — do it for each one

# over items, directly
for n in [3, 7, 11]:
    print(n * 2)
# over a range of numbers
result = 1
for i in range(1, 6):
    result *= i
print(result)  # 120 — 5!
range(1, 6) counts 1, 2, 3, 4, 5 — the stop value is not included. The loop variable (n, i) takes each value in turn, and the indented body runs once per value.

while loops — do it until told to stop

numbers = [1, 2, 3, 4, 5]
count = 0
i = 0
while i < len(numbers):        # checked BEFORE every pass
    if numbers[i] % 2 == 1:
        count += 1             # shorthand: count = count + 1
    i += 1                     # forget this line → infinite loop
print(count)                   # 3
for — when you know how many times (or have a collection to walk).
while — when you only know the stopping condition. You manage the counter — and you make it stop.

Comprehensions — a loop, folded into one line

# the loop pattern
squares = []
for x in numbers:
    squares.append(x ** 2)
# the same thing, folded
squares = [x ** 2 for x in numbers]
Read it aloud: "x squared, for each x in numbers." Same loop, same result — built for the very common pattern transform every item into a new list. Use the loop form when the body gets complicated.

Anatomy of a function

Input via parameters → behavior in the body → output via return. A named, reusable block: a black box you can call again and again.
def calculate_average(numbers: list) -> float:
    """Return the average of a list of numbers."""
    total = sum(numbers)
    num_items = len(numbers)
    avg = total / num_items
    return avg

avg1 = calculate_average([1, 2, 3])    # → 2.0
avg2 = calculate_average([4, 5, 6])    # same recipe, new input

The return value lands in the variable at the call site. Define once, call forever — that's why functions exist.

Putting it together: numbers + booleans + strings

def calculate_statistics(number1: int, number2: float) -> str:
    """Calculates and returns a summary of statistics."""
    sum_result = number1 + number2  # Addition
    product = number1 * number2     # Multiplication
    is_odd = number1 % 2 == 1       # Modulo: remainder check

    summary = (f"Sum: {sum_result}\n"
               f"Product: {product}\n"
               f"{number1} is {'odd' if is_odd else 'even'}")
    return summary

print(calculate_statistics(3, 4.5))

Docstring says what it does · annotations say what goes in and out · comments say why. That's the standard for this course.
