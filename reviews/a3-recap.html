Lesson 1 — Comments first isn't decoration

The method was: English plan → code under each line → trace. Three homework submissions had no plan at all, even though all three of those students wrote real plans in the lab. The plan is the assignment. A function with no step comments earns 0 on the comment point.

What a plan comment sounds like (yours, anonymized)

⭐ # Stop one position early because every calculation also needs the next reading
⭐ # interest first, then deposit, because order matters
⭐ # stop when there are not enough weeks left to make a full window
⭐ # If we started at or above the target, the loop never ran
Notice: every one says why, and every one would still make sense if you covered the code. Also: reusing class vocabulary (like "hand back the survivors") is exactly right. That's learning the pattern.

Lesson 4 — In Python, indentation is meaning

def velocities(positions, dt):
    result = []
    for i in range(len(positions) - 1):
        result.append((positions[i+1] - positions[i]) / dt)
        return result        # ← one indent too far
iresult after appendnext line
0[2.0]return: the function ends here, on the first pass
Same letters, different program. A return inside the loop ends on pass one. An append outside the loop keeps only the last value. An else lined up with for instead of if means something else entirely. A one-row trace catches all three instantly.
